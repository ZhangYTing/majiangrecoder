- `src/App.vue` 与 `src/style.css` 为全部主页面提供固定窗口框架，顶部操作和导航保持可见，内容区域按剩余宽高分配空间。开场、记分、历史、总账均不再出现浏览器最右侧的整页滚动条。保存异常时也保留当前场的布局；极小窗口在面板内部允许滚动，不通过裁切使内容失去访问入口。

## 限制与未验证部分

- 普通 HTTP 文件下载对照返回文件；相同浏览器中的程序触发和直接点击 Blob 下载，以及 Data URL 下载均未返回文件事件。因此不宣称本环境中的 JSON 文件导出已成功；文本复制与恢复是已验证的备用方式。
- 没有验证真机手机连接、防火墙和公网部署；没有改变这些设置。
- 存储容量异常和损坏账本主要由单元测试验证，没有用浏览器设置人为破坏用户存储。
- 无 Web Locks 的环境必须只在一个页面记分；没有承诺该环境的并发安全。
