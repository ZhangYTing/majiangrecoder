# 麻将记分器设计

用户已于 2026-09-29 在对话中确认开发以下方案。

- Vue 纯前端，手机优先，单人统一记账。无后端、账号、网络同步。
- 固定四位玩家，身份 ID 永久固定；名称可更改，成绩仍跟随身份。
- 开场安排东南西北，一场内固定座位；下一场可以重新安排。
- 点炮所有另外三人各付一个底注，自摸各付两倍底注，默认底注 1 元。无杠和庄奖励。
- 每局唯一胡牌者；流局所有金额为零；撤销只允许当前场最后一局。
- 金额以整数分计算，从局记录推导本场和总账，避免存储总分与明细不一致。
- 结束后归档，保留时间、座位、底注和每局明细。历史只读，新场不删除旧场。
- 总账含所有已归档场次和当前进行中场次；统计参加场数、胡牌次数、点炮、自摸及净输赢。
- localStorage 每次操作即时保存，保存成功才更新界面；保存异常必须提示并阻止继续记账。
- 异常存储不得自动覆盖；多标签页过期写入不得覆盖新数据，提示刷新。
- JSON 备份含所有人员、场次和当前场。导入先校验并展示摘要，经确认后替换本地记录；提供先导出入口。
- 不删除历史、不增加支付、手牌判断、复杂历史编辑或多人同步。

页面：记分、历史、总账。人员设置和备份入口放在页头。空记录引导开场，历史提供场次详情。所有破坏当前记录的动作使用清晰的确认框。

验证：Node 内置测试覆盖八种胡牌组合、底注精度、流局撤销、归档与跨场换座、改名、非法备份和保存故障；Vite 生产构建；实际浏览器执行开场、记分、刷新恢复、撤销、归档、跨场总账和手机布局。
