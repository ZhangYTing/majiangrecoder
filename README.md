# 四方账 · 麻将记分器

固定四位牌友使用的 Vue 纯前端记分器。手机和电脑都可操作，无需后端或登录。

## 运行

当前项目已安装依赖。Windows PowerShell 在项目目录运行：

```powershell
Set-Location E:\majiangrecorder
npm.cmd run dev
```

电脑打开 **http://localhost:5173/**。端口被占用时会提示错误，不会悄悄切换到新端口，让原有记录看起来消失。

首次从源代码安装时运行 `npm.cmd ci`。依赖版本由 `package-lock.json` 固定；npm 缓存位于项目的 `.npm-cache`。已在 Node.js 22.17.1 / npm 10.9.2 验证。

手机与电脑在同一局域网时，可使用启动输出中的 Network 地址访问。需要电脑保持运行，且网络允许访问该端口；没有修改防火墙设置，也没有进行实机手机连通测试。

例如本机局域网 IP 为 `192.168.3.33` 时，其他设备打开 `http://192.168.3.33:5173/`，电脑必须先运行 `npm.cmd run dev`。IP 以当前网络为准。能访问同一页面不代表共享账本：各设备、浏览器和访问地址的记录独立保存，不会自动同步。

## 使用

1. 输入四位玩家姓名并安排东南西北，点击“下一步，设置底注”，核对底注和座位后开场。返回上一步会保留已填写的内容。
2. 点击胡牌玩家，选择点炮胡或自摸，核对金额后记下一局。
3. 流局金额为零。记错了可以撤销当前场的最后一局，再重新记录。
4. 结束本场时确认四人的最终金额，归档后在历史中查看。下一场从零开始，总账继续累计。
5. 总账包含当前场和全部历史，按固定人员身份汇总；改名和下一场换座不改变成绩关联。
6. 页头的“清空全部记录”按钮会先弹出确认。确认后清空历史、总账和当前场，姓名恢复为“玩家1～玩家4”，回到首次开场页面。此操作不可撤销；取消不会改动任何记录。

默认底注 1 元：点炮时另外三人各付 1 元，胡牌者 +3 元；自摸时另外三人各付 2 元，胡牌者 +6 元。每局唯一胡牌者，无杠和庄家的额外奖励。底注可以设置为 0.01～10000 元，同一场内不变。

开场、记分、历史和总账共用随窗口宽高伸缩的页面框架，不出现浏览器最右侧的整页滚动条。历史场次与每局明细根据可用空间分页，缩放会调整每页数量并保留正在查看的记录范围，不会删除记录。开场分为两步；总账在电脑上横排四人，手机上排成两行；窄窗口的当前场通过“牌桌记分 / 本场明细”切换查看。

常用电脑、手机窗口内，内容和主要操作可完整显示。极小窗口或内容异常长时，面板内部允许滚动，以保障信息和操作仍可访问；整页不会滚动。手机尺寸已通过浏览器模拟检查，尚未做真机验证。

## 数据保存

每次操作先写入 localStorage，保存成功才更新页面。刷新、关闭后重开会恢复当前场和历史。没有网络同步，数据保存在使用的浏览器里，不是保存在项目文件夹中。

**请固定使用同一设备、浏览器和地址。** `localhost`、`127.0.0.1`、局域网 IP 和不同端口属于不同保存位置；开发页面 5173 和生产预览 4173 的账本也是独立的。

清除网站数据、无痕模式结束、浏览器重置可能使记录丢失。损坏的存储不会被自动覆盖，页面会停止记分以保护原数据。当前版本不提供备份导入、导出和手动恢复功能。

**同一时间只在一个页面记分。** 多页面查看可以使用；收到更新提醒的页面需要刷新。浏览器支持 Web Locks 时，提交使用跨页面独占锁；在非 HTTPS 的局域网地址等没有 Web Locks 的环境，过期检查不等于完整的并发互斥保护。记录上限为 5000 个历史场次、100000 局，浏览器自身的存储容量可能先达到上限，保存失败时会提示并保留旧记录。

## 验证与构建

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run preview
```

生产预览地址为 http://localhost:4173/。`dist` 内是构建后的静态文件，可交给静态网站服务器托管；不要直接双击 `dist/index.html`。没有发布到公网，也没有增加 PWA 离线缓存。

使用 Node 内置测试，无额外测试框架。实际验证记录见 [docs/verification.md](docs/verification.md)。

## 文件职责

| 文件                              | 职责                                           |
| --------------------------------- | ---------------------------------------------- |
| `src/domain/recorder.js`          | 计分、场次转换、跨场汇总，金额以整数分计算     |
| `src/domain/backup.js`            | 本地记录的格式、人员和状态校验，沿用原存储格式 |
| `src/storage.js`、`src/commit.js` | 存储保护、过期检查及独占提交                   |
| `src/composables/useRecorder.js`  | Vue 状态、先保存后更新、跨页面更新提示         |
| `src/App.vue`                     | 页面导航、记分确认和姓名设置弹窗               |
| `src/components/`                 | 开场、牌桌、局明细、历史和总账                 |
| `src/layout/pagination.js`、`src/composables/useGridPagination.js` | 窗口容量计算和历史自适应分页 |
| `tests/`                          | 业务、存储、分页测试及浏览器验证用测试数据     |

测试备份属于测试数据，不会自动载入应用，也不包含在生产构建中。浏览器验证使用独立地址，不操作用户 `localhost:5173` 的账本。
